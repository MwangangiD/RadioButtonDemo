# Java RadioButtonDemo (OOP 2 Assignment)

A Java Swing application demonstrating the use of `JRadioButton`, `ButtonGroup`, event listeners, dynamic image display, and message dialogs (`JOptionPane`).

## Features
- Five radio buttons for pet selection (Bird, Cat, Dog, Rabbit, Pig).
- Dynamic image rendering scaled smoothly to the window.
- Informational message box popup on each selection.
